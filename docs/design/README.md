## 세 안 요약

| | 성격 | 언제 유리한가 |
|---|---|---|
| **1a** | 기간 세그먼트 하나가 아래 전체를 전환 | 기간 혼동을 확실히 없애고 싶을 때 |
| **1b** | 상단이 "무엇 · 누구 · 버튼" 할 일 목록 | 원장이 30초에 끝내야 할 때 |
| **1c** | 화면 전체가 학생 표, 기간이 열을 바꿈 | 학생 100명 이상 |

파트너 추천은 **1a 구조 + 1b의 할 일 목록**입니다.

## 이번 제안의 핵심 3가지

1. **시간축 3개 → 1개.** "이번 주 현황"만 기간과 분리해 고정, 날짜 선택기와 기간 토글은 통합.
2. **학생 상세 2벌 → 1벌.** 풀 모달의 기능을 420px 오버레이 드로어에 담고, 이전/다음 학생 이동 추가.
3. **모든 집계를 학생 배열에서 파생.** 지금의 "1명 vs 4건" 불일치를 구조적으로 불가능하게.
