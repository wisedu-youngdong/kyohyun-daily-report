# 원장 보고서 화면 — 설계 전 조사 요청

디자인을 다시 그리기 전에, 코드베이스를 보고 아래를 확인해 주세요.
**아직 코드는 수정하지 마시고 조사 결과만 정리해 주세요.**

대상 화면: 원장분석 탭 > 원장보고서 (+ 학생 클릭 시 우측 상세 패널)

---

## A. 지금 이 화면이 답하는 질문

1. 원장이 이 화면을 여는 실제 상황이 무엇인가요? 매일 아침인가요, 주 1회인가요?
   접속 로그나 라우팅 기록으로 확인 가능한지 알려주세요.
2. 상단 탭 3개(원장보고서 / 원장분석 / 주간 리포트 검토)의 역할 구분이
   코드상 어떻게 나뉘어 있나요? 데이터가 겹치는 부분이 있나요?

## B. 세 개의 시간축 — 가장 큰 문제

한 스크롤 안에 서로 다른 기간이 세 번 나옵니다.

- 상단 "이번 주 현황 · 8월 0주차" — 주간
- 중간 "원장님 데일리 보고서" + 날짜 선택 — 특정 하루
- 하단 KPI 4장 + 추이 차트 + 학생 표 — 3일 / 2주 / 1개월 / 6개월 별도 토글

3. 이 세 블록이 각각 어떤 쿼리·상태를 쓰는지 알려주세요.
4. 날짜 선택기를 바꾸면 어떤 블록이 반응하고 어떤 블록이 반응하지 않나요?
5. 이 셋을 **기간 컨트롤 하나**로 통합할 때 깨지는 로직이 있나요?
   (예: 주간 카드는 항상 이번 주 고정이어야 하는 이유가 있는지)

## C. 숫자가 서로 맞지 않음

같은 화면에 미제출 수치가 두 개 나옵니다.

- 상단: **1명** 미제출
- 날짜 섹션: **4** 리포트 미작성

6. 두 값이 각각 어떤 필드·조건으로 계산되나요?
7. "미제출"과 "리포트 미작성"이 다른 개념인가요? 다르다면 정확한 정의는?
8. 8월 2일(일요일)에 총 수업 0 / 정시 출석 0 / 결석 0 인데 미작성이 4건인 이유는?

## D. 빈 상태

9. 날짜 선택기의 기본값이 무엇인가요? (오늘? 마지막 조회일?)
10. **"가장 최근 수업이 있었던 날"을 기본값으로 바꿀 수 있나요?**
    수업일 여부를 판별할 필드가 있는지 알려주세요.
11. 수업이 없는 날(주말·휴원)과 수업은 있었으나 리포트가 없는 날을
    구분할 수 있나요? 지금은 둘 다 같은 빈 박스입니다.

## E. KPI 4장

관심 필요 1명 / 전체 평균 71.7% / 총 학생 4명 / 최고 학생 김호현

12. "관심 필요"의 판정 기준(경고·주의 임계값)은 어디에 정의돼 있나요?
    원장이 조정할 수 있나요, 고정값인가요?
13. "최고 학생"은 어떤 요구로 들어간 항목인가요?
    (원장 액션이 없는 정보라 위치를 낮추거나 뺄 후보로 보입니다)
14. "전체 평균 71.7%"는 무엇의 평균인가요? 개념 이해? 과제? 혼합?

## F. 학생 표

15. 상태 3종(경고 / 주의 / 안정)과 "데이터 없음"의 판정 조건은?
16. 변화량(▼10 / ▲10)은 무엇 대비인가요? 직전 수업? 기간 평균?
17. 표 옆 작은 화살표 스파크라인은 몇 개 데이터 포인트를 쓰나요?
18. 정렬 3종(관리 목록순 / 점수 낮은 순 / 이름순)에서 기본값은?

## G. 우측 학생 패널

19. 패널이 열릴 때 본문이 밀리는 push 레이아웃입니다.
    폭은 어디서 정해지나요? 오버레이로 바꿀 때 걸리는 제약이 있나요?
20. 패널 안의 리포트 목록은 몇 건까지 가져오나요? 별도 쿼리인가요,
    이미 로드된 데이터의 필터인가요?
21. 하단 "선택 / 최근 3개월" 두 버튼은 각각 무엇을 하는 컨트롤인가요?
22. **이전/다음 학생 이동**을 넣으려면 표의 정렬 순서를 패널이 알아야 합니다.
    현재 구조에서 가능한가요?
23. "성장 포트폴리오 보기·편집"은 같은 탭 이동인가요, 새 창인가요?
24. 패널에서 바로 할 수 있어야 하는 액션이 더 있나요?
    (예: 담당 선생님에게 리포트 작성 요청, 학부모 연락)

## H. 버그로 보이는 것

25. **"8월 0주차"** — 주차 계산 로직 위치와 원인을 알려주세요.
26. 학생 표에 "서우성"이 있는데 상단 알림에도 "리포트 미작성 서우성"이 뜹니다.
    같은 사람인가요? 표에는 "서우영"과 "서우성"이 둘 다 있습니다.

## I. 알림 / 접힌 섹션

27. 상단 "답변 완료 · 1건", "학부모 참여도 조정 필요 3명"은
    각각 어떤 데이터인가요? 펼치면 무엇이 나오나요?
28. 이 둘이 접혀 있어야 하는 이유가 있나요?
    (지금은 펼치기 전까지 정보가 0이라 클릭이 강제됩니다)
29. "리포트 미작성 서우성" 알림을 누르면 무슨 동작을 하나요?

## J. 규모

30. 학원당 학생 수가 최대 몇 명까지 늘어날 수 있나요?
    지금 화면은 4명 기준으로 그려져 있는데, 40명·200명이면
    표·KPI·패널 설계가 달라집니다.
31. 선생님이 여러 명일 때 원장 보고서에 선생님별 구분이 필요한가요?

---

## 조사 후 정리해 줄 것

1. 위 항목별 답변
2. **B(시간축 통합)와 C(숫자 불일치)** 에 대한 본인 의견 — 이게 설계의 핵심 갈림길입니다
3. H의 버그 2개는 수정 난이도만 알려주세요 (수정은 승인 후)

이 답변을 받아야 화면 구조를 다시 그릴 수 있습니다.
