# 디자인 의뢰 — 선생님 피드백 3단 구조 카드

## 배경
경쟁사(원클릭학원 등) 리포트를 보니 교사 피드백을 "잘하고 있는 점 / 보완이 필요한 점 / 선생님 한마디" 3단으로 구조화해서 보여주고 있었음. 지금 우리 앱은 이 부분이 자유 텍스트 한 덩어리(teacherNote)라 학부모가 스캔하기 어려움 — 이걸 3단으로 구조화하기로 결정.

**주의**: 참고한 경쟁사 리포트는 "주간/월간 종합 리포트"(여러 과목을 한 번에 다룸)지만, 우리 리포트는 "세션 1건 = 하루치 숙제/테스트 1개"임. 그대로 베끼면 안 맞으니, 저 참고 이미지에서는 **3단 구조라는 컨셉만** 가져오고 레이아웃/문구는 우리 상황에 맞게 새로 짜야 함.

## 확정된 결정사항
1. **입력 방식 안 바꿈** — 선생님은 지금처럼 메모 하나만 대충 쓰고 AI가 다듬는 원클릭 흐름 그대로. "잘한 점/보완할 점"을 선생님이 직접 나눠 쓰게 하지 않음(부담 커짐, 예전에 여러 버튼을 하나로 통합했던 결정과도 배치됨).
2. **AI가 통째로 생성** — teacherNote 원문을 AI가 "잘하고 있는 점" / "보완이 필요한 점" 2단으로 나눠 쓰고, 기존에 이미 있던 "오늘의 한 줄"(summary)을 "선생님 한마디" 역할로 재사용. 새 필드를 3개가 아니라 2개만 추가하면 됨.
3. **기존 리포트도 일괄 재처리** — 마이그레이션 스크립트로 예전 리포트도 새 구조로 채워 넣음. 즉 화면에는 "옛날 데이터 폴백" 분기가 필요 없고, 모든 리포트가 항상 3단 구조로 존재한다고 가정하고 디자인하면 됨.

## 데이터 (디자인 시 이 필드들이 항상 존재한다고 가정)
- `summary` (기존 필드, 이미 있음) — 15~30자 한 줄 요약. → **"선생님 한마디"** 역할
- `teacherNote.strengths` (신규) — 잘하고 있는 점, AI 생성, 1~2문장
- `teacherNote.improvements` (신규) — 보완이 필요한 점, AI 생성, 1~3문장 (오답 문항 구체적 언급 포함될 수 있음 — 문장이 좀 길어질 수 있다는 뜻)

## 지금 화면 구조 (참고 — `PublicReport.jsx`, 학부모가 카톡 링크로 여는 공개 리포트)
아래 순서로 카드 섹션들이 세로로 쌓여 있음. 새 3단 피드백은 **"선생님 노트" 자리를 대체**함:

```
[헤더 — 어두운 배경, 학생명/출결/날짜]
[오늘의 한 줄 — 옅은 색 배너, summary 텍스트]
[핵심 지표 — 과제/개념 막대그래프 2개]
[학습 범위 카드 — 교재/단원/페이지]
[TEST RESULT — 점수 있을 때만]
[선생님 노트 ← 여기를 3단 구조로 새로 디자인]
[사진 그리드 — 있을 때만]
[다음 수업 카드]
[질문하기]
```

## 제약 조건 (반드시 지킬 것)
- **화면 폭 390px 고정 프레임**(`ReportCard` 컴포넌트) 안에 들어가야 함 — 학부모가 카카오톡 인앱 브라우저로 폰에서 봄. 데스크톱 고려 안 해도 됨.
- **새 색상 팔레트 도입 금지** — 학원마다/학생마다 색이 다르게 커스터마이징되는 "스킨" 시스템이 이미 있음(`sk.primary`, `sk.accent`, `sk.tint`, `sk.second`, `sk.track`, `sk.bannerLabel` — 각각 주조색/포인트색/옅은배경/보조색/트랙배경/라벨텍스트 역할). 새 색을 하드코딩하지 말고 이 역할들 중에서 골라 쓰는 식으로 설계해야, 학원마다 색이 바뀌어도 자동으로 맞음.
- **폰트**: Pretendard Variable (본문), Noto Serif KR(제목급 헤딩에만 가끔).
- **기존 카드 톤 유지** — 다른 섹션들처럼 라운드 카드(`border-radius: 14px` 안팎), 옅은 배경(`sk.tint`) 위에 라벨(10px, 굵게, 자간 넓게) + 본문 텍스트 조합 패턴을 그대로 따르는 게 자연스러움(완전히 다른 스타일 시스템 도입 금지).
- **새 UI 라이브러리 설치 금지** — 순수 HTML/CSS로 시안 제작.

## 요청 사항
1. 위 제약 안에서 "선생님 노트" 자리를 대체할 **3단 구조 카드**(잘하고 있는 점 / 보완이 필요한 점 / 선생님 한마디) 시안
2. 3개 섹션을 시각적으로 어떻게 구분할지(아이콘? 색 배지? 여백?) — 경쟁사처럼 각기 다른 색을 쓸지, 아니면 우리 스킨 시스템 안에서(sk.primary/sk.accent/sk.tint 조합) 구분할지 제안 부탁
3. 텍스트 길이가 짧을 때/길 때(보완할 점이 여러 문장일 때) 모두 자연스러운지
4. 완성된 시안은 `.dc.html`(또는 순수 HTML) 파일 + 결정해야 할 사항 목록 형태로 — 실제 구현은 우리 쪽 React 코드 스타일로 옮길 예정이라, 시안 문법을 그대로 옮기진 않고 레이아웃·색 역할·간격·문구만 참고함
