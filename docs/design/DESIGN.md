# 디자인 기준 — 교현리포트 (리포트 스킨 / 리포트 UI)

색·폰트·간격을 추측하지 말고 아래 값을 그대로 쓴다.
바인딩된 디자인 시스템(`_ds/design-system-291cb5aa-…/tokens/*.css`)에 값이 있으면 **그 파일이 최종 기준**이고, 이 문서는 그 안에서 실제로 쓰는 부분집합이다.

## 브랜드 한 줄 정의

- 학원 선생님이 매 수업 후 작성해 학부모에게 발송하는 학습 리포트
- 주 사용자: 선생님/원장(작성), 학부모(수신 — 모바일 웹으로 열람)
- 풍겨야 할 인상: 공식 성적표에 가까운 신뢰감, 차분하고 읽기 편한 문서
- 절대 주지 말아야 할 인상: 장난감 같은 느낌, 흔한 SaaS 대시보드, 마케팅 랜딩페이지

## 스케일

- **spacing**: `4, 8, 10, 12, 14, 16, 18, 20, 22, 26, 32, 40` (리포트 카드 좌우 패딩은 `26`으로 고정)
- **radius**: badge `6` · chip/pill `20` · input `12` · 내부 블록 `14` · 카드 `16` · 리포트 패널 `18` · avatar `50%`
- **shadow**: `none` → 옅음 `0 1px 4px rgba(0,0,0,0.06)` → 중간 `0 6px 28px rgba(23,23,25,0.10)` → 강조(모달) `0 12px 40px rgba(23,23,25,0.18)`
- **타입 스케일**: display `28/700` · h2 `22/700` · h3 `17/700` · 요약문 `19/700` · body `14.5/500~600` · small `12/600` · caption `11/600` · 영문 라벨 `10.5/700 + letter-spacing 1.4~2.2`
- **수치 표기**: 값 `22~30/700`, 단위(%)는 같은 색 `12~14/600`

## 절대 쓰지 않는 것

1. Inter, Roboto, 시스템 기본 폰트 — Pretendard(대체: Noto Sans KR)만
2. 그라데이션 배경 — 톤 전환은 배경색 블록으로
3. 카드 안에 카드 — 여백·구분선으로 구획
4. 색 있는 배경 위 회색 텍스트 — 진한 배경은 흰색/알파 흰색, 옅은 배경은 팔레트의 짙은 버전
5. 바운스 이징 — `ease` / `ease-in-out`, 0.15~0.3초
6. 레인보우 카테고리 컬러

## 이 프로젝트만의 추가 금지 목록

- **개별 학생 리포트에 "반 평균" 등 다른 학생과의 비교 지표 금지.** 비교는 그 학생의 지난 수업/최근 주차 대비만.
- 이모지 금지. 아이콘은 디자인 시스템의 `IconNormal*` 세트만.
- 선생님 노트 등 텍스트 블록 앞에 이니셜 아바타·장식 원형 아이콘 붙이지 않기.
- 과장 표현 금지("AI가 완벽 분석", "100% 자동" 등). 리포트 문장은 관찰 사실 + 다음 계획 형식.
- 학부모 화면에 미완성 노트("추후에 마무리할게요")가 그대로 나가지 않도록 발송 전 확인 UI 필요.
